基础说明
========

请参阅 `应用程序 <https://infinity0.github.io/lcra/>`_ 中的帮助文本。

其他功能
========

- 可以用（⇤）键隐藏文章面板，然后直接在另个窗口中读文章。然后，在那里选择任意单词，再把它拖到添加键 (⊕) 上。
- 当没有选择任何内容时，可用添加键（⊕）来输入新单词。
- 您可以选择多个单词并一次都添加，如果它们之间用空格或换行符分隔。（把普通中文文本解析成单词是跟把它完全翻译几乎困难，这是我们在此简单程序中无法做到的。）
- 双击拼音框就把它重置为我们从所选单词自动衍生的拼音（有可能是错的）。

局限性
======

在参考面板里，由于浏览器安全策略，某些参考网站（例如百度百科）的交互功能被禁用或限制。 面板底有链接为把参考在新窗口中打开，会解除那些限制。
